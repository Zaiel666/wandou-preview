# 豌豆预览 0.1.0

- FBX、OBJ、3DS、3MF、DAE、DXF、glTF/GLB、STL、PLY、IFC、USD 等常用格式显示文件夹缩略图。
- 模型缩略图左下角显示格式，不添加模型右键菜单。
- Blender `.blend` 直接读取保存时内嵌的场景预览，支持普通与 GZip 压缩文件。
- C4D 显示场景保存图片；本机装有兼容 Cinema 4D 时自动启用。
- AI 文件含 PDF 兼容数据时显示缩略图。
- Radiance HDR 图片使用内置解码和自动曝光显示缩略图。
- 不占用空格键，不修改 QuickLook，不需要管理员权限。
- 一个 ZIP 安装包，解压后双击 `Install.cmd` 即可。
