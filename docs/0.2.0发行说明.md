# 豌豆预览 0.2.0

- 新增 MP4、AVI、MOV、M4V、WMV、ASF、MPG/MPEG、MKV、WebM、MTS/M2TS、FLV、VOB、3GP 等常用视频封面缩略图。
- 视频只提取约 10% 位置的一帧，不播放、不修改文件。
- MP4、AVI、MOV、M4V、WMV、ASF 和 3GP 使用 Windows 自带 Media Foundation 解码，无需安装官方剪辑软件或 SDK。
- 保留 Blender、FBX、OBJ、C4D、AI、HDR 等原有缩略图功能。
- 保留登录后一次性关联刷新，防止重启后缩略图处理器失效。
- 不添加文件右键菜单，不占用空格键。
- 新增单文件 `Wandou-Preview-0.2.0-Setup.exe`，双击一次自动完成当前用户安装。
