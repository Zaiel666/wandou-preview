# 0.2.0 · 通用三维模型预览版

本版把 0.1.0 的 C4D 场景图片验证扩展为通用模型缩略图和交互查看器。

- FBX、OBJ、3DS、3MF、DAE、DXF、glTF/GLB、STL、PLY、X、X3D、IFC、USD 等格式接入 Assimp 导入器。
- 文件夹缩略图自动居中模型，左下角显示格式名称。
- 右键“3D 模型快速预览”打开真正的三维窗口：旋转、平移、缩放和视角复位。
- 右键菜单和应用使用新的金属立方体图标。
- 通用模型功能不依赖任何官方三维软件；本机有兼容 C4D 组件时继续启用 C4D 场景图片。
- 自动迁移本项目 0.1.0 安装，卸载恢复之前的缩略图关联。
- QuickLook 和空格键不受影响。

当前渲染重点是可靠显示静态网格和基础材质颜色。复杂贴图、动画、程序化材质及插件对象仍需迭代。Alembic、Bullet、Forger、Illustrator、Redshift Proxy、OpenVDB 和 VRML 尚未加入。
