# 0.1.0 · C4D 验证版

本版优先解决在 Windows 文件夹里识别 C4D 场景的问题。

- 读取场景中保存的预览图片，不需要启动 Cinema 4D 主界面。
- 文件夹缩略图左下角显示小型 C4D 文字标识。
- 右键“C4D 快速预览”打开图片窗口，支持滚轮缩放、拖动平移和适合窗口。
- 缩略图解析使用独立工作进程，限制 12 秒和 512 MiB 内存。
- 每用户安装，提供恢复原注册设置的卸载脚本。
- 不注册空格快捷键，保留 QuickLook 的原有使用方式。

## 安装

下载 `C4D-QuickPreview-0.1.0-Windows-x64.zip`，完整解压，双击 `Install.cmd`。详细步骤见 [安装与使用](安装与使用.md)。卸载运行 `Uninstall.cmd`。

## 本版限制

需要本机已有可用的 Cinema 4D `win_thumbnail.dll`。安装包不包含 Maxon 专有组件。已保存图片只能进行二维缩放和平移，不能旋转三维场景。HDR、Blender、FBX、OBJ 等格式尚未实现。

这是一版未签名的试用工具，兼容性测试范围有限。图片质量和内容取决于场景保存的预览；大型场景、不同 C4D 版本和没有预览的文件需要继续验证。
