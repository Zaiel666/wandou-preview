# 豌豆预览 0.1.0 · 安装与使用

## 最简单的安装方法

1. 从 GitHub Releases 下载 `Wandou-Preview-0.1.0-Windows-x64.zip`。
2. 右键 ZIP，选择“全部解压”。
3. 打开解压后的文件夹，双击 `Install.cmd`。
4. 看到“豌豆预览 0.1.0 安装完成”后关闭黑色窗口。
5. 重新打开模型所在文件夹，选择“大图标”或“超大图标”。

这是当前用户安装，不需要管理员权限。安装器会自动迁移本项目以前的 C4D Quick Preview 注册。它不占用空格键，不改变 QuickLook，也不会改变文件的默认打开软件。

## 右键预览

右键 FBX、OBJ 等模型，选择“3D 模型快速预览”。Windows 11 旧式菜单中，该命令可能位于“显示更多选项”内。

| 操作 | 功能 |
| --- | --- |
| 左键拖动 | 旋转模型 |
| 中键或右键拖动 | 平移模型 |
| 鼠标滚轮 | 缩放 |
| 双击左键、Home 或 R | 恢复视角 |
| Esc | 关闭窗口 |

C4D 和 AI 的右键窗口显示二维预览图，支持滚轮缩放和左键拖动。

## AI 文件说明

`.ai` 预览依靠文件中的 PDF 兼容数据。若看不到，请在 Illustrator 另存文件时勾选“创建 PDF 兼容文件”。旧式纯 PostScript AI 文件没有这部分数据，豌豆预览不会假装生成错误画面。

## 看不到缩略图

1. 把文件夹切换到“大图标”或“超大图标”。
2. 在文件夹选项中取消“始终显示图标，从不显示缩略图”。
3. 关闭并重新打开文件夹。若仍显示以前的彩色水滴图标，可用 Windows“磁盘清理”清除“缩略图”缓存。
4. 先试右键预览。窗口能正确显示而文件夹仍是旧图，通常只是系统缓存。
5. OBJ 的 MTL/贴图、glTF 的 BIN/图片等外部文件应保留在正确位置。
6. 首次读取大模型可能需要数秒；超过 20 秒或约 1 GiB 工作内存会自动停止。

## C4D 路径

安装时会自动寻找 Cinema 4D。没有找到时，FBX、OBJ、AI 等功能仍可使用。手动指定命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -Cinema4DPath "D:\Maxon Cinema 4D 2023"
```

参数也可以直接填写 `win_thumbnail.dll` 的完整路径。

## 卸载

双击解压目录中的 `Uninstall.cmd`。若解压目录已删除，可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\WandouPreview\0.1.0\Uninstall.ps1"
```

- 程序目录：`%LOCALAPPDATA%\WandouPreview\0.1.0`
- 安装前关联备份：`%LOCALAPPDATA%\WandouPreview\registry-backup.json`
- C4D/AI 图片缓存：`%LOCALAPPDATA%\WandouPreview\Cache`

卸载不会强行关闭资源管理器或删除系统缩略图数据库。退出预览并注销 Windows 后，可以手动删除剩余目录。
