# 安装与使用 · 0.2.0

## 从旧版升级

新版安装器会识别本项目 0.1.0 的注册备份并调用旧版卸载器，然后安装 0.2.0。若旧版程序目录被手工删除而注册还在，请先重新解压并安装 0.1.0，再运行它的 `Uninstall.cmd`，之后安装新版。

不要同时安装多个三维缩略图工具。Windows 对同一扩展名通常只采用一个缩略图处理器；0.2.0 安装时会保存当前关联，卸载时再恢复。

## 安装步骤

1. 从 Releases 下载 `Model-QuickPreview-0.2.0-Windows-x64.zip`。
2. 完整解压；不要只在压缩包窗口里直接运行安装器。
3. 双击 `Install.cmd`。这是当前用户安装，不需要管理员权限。
4. 关闭原来的模型文件夹，再重新打开并选择“大图标”或“超大图标”。
5. 右键 FBX、OBJ 或其他支持格式，选择“3D 模型快速预览”。Windows 11 可能要先点“显示更多选项”。

安装不改变 FBX、OBJ、C4D 等文件的默认打开程序，不占用空格键，不更改 QuickLook，不会上传模型。

## 交互方式

| 操作 | 功能 |
| --- | --- |
| 左键拖动 | 旋转模型 |
| 中键或右键拖动 | 平移 |
| 鼠标滚轮 | 缩放 |
| 双击左键、Home 或 R | 恢复自动居中视角 |
| Esc | 关闭预览窗口 |

通用模型窗口展示静态网格。骨骼动画、约束、粒子、程序化材质、第三方渲染器节点和某些贴图功能暂不会完整还原。

`.c4d` 使用场景文件保存时的二维图片，所以只有缩放和平移；要旋转 C4D 原生场景仍需真正读取其几何和插件数据，这不属于当前独立读取路径。

## 看不到缩略图时

1. 确认文件夹使用“大图标”或“超大图标”，并在文件夹选项中取消“始终显示图标，从不显示缩略图”。
2. 关闭并重新打开文件夹。若 Windows 已缓存旧的失败图标，可以在 Windows“磁盘清理”中清除“缩略图”缓存。
3. 右键执行“3D 模型快速预览”。窗口能打开而缩略图仍旧，通常是系统缓存；窗口也报错则是该文件解析失败。
4. 检查模型的外部资源是否仍在原位置，例如 OBJ 的 MTL、glTF 的 BIN/图片、FBX 引用贴图。
5. 特别大的文件首次生成可能接近 20 秒。超过时间或约 1 GiB 工作内存会停止，资源管理器不会无限等待。
6. `.abc`、`.bullet`、`.fpk`、`.ai`、`.rs`、`.vdb`、`.wrl` 以及普通 `.xml` 当前未注册，不能仅凭扩展名得到可靠预览。

## 自定义 C4D 位置

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -Cinema4DPath "D:\Maxon Cinema 4D 2023"
```

参数可以是 Cinema 4D 目录或 `win_thumbnail.dll` 完整路径。没有这个组件时，安装器仍然安装全部通用三维格式，只跳过 C4D。

## 卸载和文件位置

双击 `Uninstall.cmd`。若解压文件夹已经删除，可以运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\C4DQuickPreview\0.2.0\Uninstall.ps1"
```

- 程序：`%LOCALAPPDATA%\C4DQuickPreview\0.2.0`
- 安装前关联备份：`%LOCALAPPDATA%\C4DQuickPreview\registry-backup-v0.2.json`
- C4D 右键图片缓存：`%LOCALAPPDATA%\C4DQuickPreview\Cache`

卸载不会强行关闭资源管理器或删除系统缩略图数据库。退出所有预览并注销 Windows 后，可以手动删除剩余程序目录。
