# 安装与使用 · 0.1.0

## 先看本版能做什么

| 功能 | 本版状态 |
| --- | --- |
| 文件夹显示 C4D 场景保存的缩略图 | 已实现，依赖本机可用的 C4D 缩略图 DLL |
| 缩略图左下角小标识 | 已实现，蓝底 C4D 文字，不是官方图标素材 |
| 右键打开预览窗口 | 已实现，Windows 11 可能要进入“显示更多选项” |
| 图片缩放、拖动平移 | 已实现 |
| 旋转三维模型 | 未实现；保存的二维图片不含可旋转的几何数据 |
| HDR、Blender、FBX、OBJ 等 | 后续范围，本版未实现 |
| 不占用空格键 | 已实现，程序不注册全局快捷键 |

## 安装步骤

1. 下载 Releases 中的 Windows x64 ZIP，完整解压。
2. 双击 `Install.cmd`，看到“安装完成”后关闭窗口。
3. 打开含 C4D 模型的文件夹，切换“大图标”或“超大图标”。
4. 右键模型，选择“C4D 快速预览”。

安装脚本只修改当前用户的缩略图处理器和该工具的右键菜单注册，不改变 `.c4d` 默认打开程序，不修改 QuickLook 配置，不将你的模型上传到服务器。安装包未签名；Windows 可能显示下载或运行提示，请核对下载来源和发行页 SHA-256。

## C4D 安装在其他磁盘

在解压文件夹打开 PowerShell，执行（替换为你实际的目录）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -Cinema4DPath "D:\Maxon Cinema 4D 2023"
```

也可以直接传入本机 `win_thumbnail.dll` 的完整路径。程序不会从网上下载或分发这个专有组件。安装器发现 DLL 并不等于该组件支持所有 C4D 文件；发现无法预览时按下面排查。

## 看不到缩略图

1. 确认该文件是 `.c4d`，并采用“大图标”或“超大图标”视图。
2. 在文件资源管理器选项 → 查看中，取消“始终显示图标，从不显示缩略图”。
3. 先尝试右键预览。若右键能看到，但文件夹看不到，可能是 Windows 缓存或尚未重新加载扩展；关闭文件夹后重新打开，必要时注销再登录。
4. 如果右键也没有图片，用 C4D 打开该文件并保存一个有效的场景预览后重试。本工具不会自动修改你的原文件。
5. 旧组件可能不认识新版本场景，请使用本机更合适的组件。更换组件之前先卸载此工具，再指定新位置安装。
6. 如仍显示旧图，可自行使用 Windows“磁盘清理”里的“缩略图”清理选项；安装器不自动清理全系统缓存。

场景预览是保存时的图片，未必是当前相机的最终渲染。它的清晰度取决于原文件，放大后可能模糊。

## 卸载及文件位置

双击 `Uninstall.cmd`。若解压文件夹已经删除，也可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\C4DQuickPreview\0.1.0\Uninstall.ps1"
```

- 程序：`%LOCALAPPDATA%\C4DQuickPreview\0.1.0`
- 右键窗口图片缓存：`%LOCALAPPDATA%\C4DQuickPreview\Cache`
- 安装前注册值备份：`%LOCALAPPDATA%\C4DQuickPreview\registry-backup.json`

卸载恢复注册信息，保留程序及缓存，防止删除正在被 Windows 使用的 DLL。注销 Windows 后可以手动删除该工具目录。

## 测试反馈

反馈 C4D 版本、Windows 版本、文件大致大小、文件夹缩略图和右键预览分别是否成功即可。不要为了反馈上传保密场景。
