# 豌豆预览 0.2.0 · 安装与使用

## 最简单的安装方法

1. 从 GitHub Releases 下载 `Wandou-Preview-0.2.0-Setup.exe`。
2. 双击安装程序。
3. 看到“豌豆预览 0.2.0 已安装完成”后，打开文件夹并选择“大图标”或“超大图标”。

这是当前用户安装，不需要管理员权限。安装器会自动迁移本项目以前的 C4D Quick Preview 注册，并清理旧版添加的右键预览菜单。它只负责文件夹缩略图，不占用空格键，不改变 QuickLook，也不会改变文件的默认打开软件。

安装器会添加 `WandouPreviewRefresh` 当前用户登录项。它在登录后等待约 3.5 秒，通知资源管理器重新加载缩略图关联，然后立即退出，不会常驻后台；卸载时会恢复原来的登录项设置。

## Blender 文件说明

`.blend` 缩略图来自文件中保存的场景预览，读取时不会启动 Blender，也不依赖 Blender SDK。普通保存和 GZip 压缩保存都支持。若某个文件没有内嵌预览，请使用 Blender 打开并重新保存一次。

## 视频文件说明

视频只生成静态封面缩略图，不播放视频，也不会修改视频。程序会优先读取约 10% 位置的一帧，避免片头黑屏。

程序先使用 Windows 原生媒体组件读取 MP4、AVI、MOV、M4V、WMV、ASF 和 3GP。遇到系统未安装 HEVC 等解码器，或 MKV、WebM、FLV、MTS/M2TS、VOB 等其他容器时，会自动切换到安装包内的 FFmpeg 解码组件，不要求另装视频软件或商店扩展。

## AI 文件说明

`.ai` 预览依靠文件中的 PDF 兼容数据。若看不到，请在 Illustrator 另存文件时勾选“创建 PDF 兼容文件”。旧式纯 PostScript AI 文件没有这部分数据，豌豆预览不会假装生成错误画面。

## 看不到缩略图

1. 把文件夹切换到“大图标”或“超大图标”。
2. 在文件夹选项中取消“始终显示图标，从不显示缩略图”。
3. 关闭并重新打开文件夹或按 `F5`。安装器会同步刷新文件关联缓存，并在登录 Windows 时自动刷新一次。若仍显示以前的彩色水滴图标，可用 Windows“磁盘清理”清除“缩略图”缓存。
4. OBJ 的 MTL/贴图、glTF 的 BIN/图片等外部文件应保留在正确位置。
5. 首次读取大模型可能需要数秒；超过 60 秒或约 3 GiB 工作内存会自动停止。

## C4D 路径

安装时会自动寻找 Cinema 4D。没有找到时，FBX、OBJ、AI 等功能仍可使用。手动指定命令：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -Cinema4DPath "D:\Maxon Cinema 4D 2023"
```

参数也可以直接填写 `win_thumbnail.dll` 的完整路径。

## 卸载

打开 Windows“设置 → 应用 → 已安装的应用”，找到“豌豆预览”，点击“卸载”。

- 程序目录：`%LOCALAPPDATA%\WandouPreview\0.2.0-构建编号`
- 安装前关联备份：`%LOCALAPPDATA%\WandouPreview\registry-backup.json`
- C4D/AI/HDR 图片缓存：`%LOCALAPPDATA%\WandouPreview\Cache`

卸载不会强行关闭资源管理器或删除系统缩略图数据库。退出预览并注销 Windows 后，可以手动删除剩余目录。
